> [!IMPORTANT]
> We don't recommend that you use the <xref:System.Net.HttpListener> class for new development. `HttpListener` receives only limited servicing, and it doesn't support modern features such as HTTP/2 and HTTP/3. Use [ASP.NET Core](/aspnet/core/fundamentals/servers/kestrel) instead, which provides a fully supported, cross-platform, and higher-performance HTTP server.
