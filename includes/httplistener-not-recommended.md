> [!CAUTION]
> We recommend that you *don't use* the <xref:System.Net.HttpListener> class for new development. `HttpListener` receives only limited servicing, and its behavior and protocol support vary by platform because each platform uses a different underlying implementation. For example, on Windows it's built on `HTTP.sys`, while on Linux and macOS it uses a managed implementation that doesn't support HTTPS and offers a narrower set of features. Use [ASP.NET Core](/aspnet/core/fundamentals/servers/kestrel) instead, which provides a fully supported, cross-platform, and higher-performance HTTP server.
